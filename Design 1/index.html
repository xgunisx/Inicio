Primeros pasos:

En los primeros pasos de HTML:5 se estudian una serie de etiquetas que nos ayudan a sedimentar las bases de toda web que queramos desarrollar. Tenemos funciones como tipografias, estilos de letra, insertar imagenes, links, etc.

A su vez, las secciones en las que agregamos la "vida" a la web, se hacen con el codigo denominado como CSS (Cascading Style Sheets). Este código se encarga especificamente de definir la presentacion visual de los documentos previamente estructurados.
